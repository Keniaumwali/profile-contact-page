
# HTML Structure & Contact Form Project

## Project Overview
This project is a personal profile webpage built using HTML5 and CSS3. It demonstrates semantic HTML structure, personal information, lists, an image, and a contact form with validation.

## Features
- Semantic HTML5 elements: header, nav, main, article, section, and footer.
- Profile image with alternative text.
- About Me section with personal interests and goals.
- Contact form with full name, email, inquiry category, and message fields.
- Newsletter subscription checkbox.
- Required-field validation.
- Black-and-white design with responsive styling.

## Technologies Used
- HTML5 — creates the webpage structure and content.
- CSS3 — styles the webpage, including colors, spacing, layout, and responsiveness.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser such as Google Chrome.

## Note
The contact form demonstrates HTML form fields and browser validation. It does not send messages to a server.

## Learning Outcomes
This project helped me practice semantic HTML, accessible form labels, form validation, CSS styling, and webpage organization.
